# PIE/custom mnemonic inventory

This is an alphabetized inventory of all 360 unique `esp.*` mnemonics found in the ESP-IDF v6.0.2 GDB stub RISC-V decoder/assembler test file `components/esp_gdbstub/test_gdbstub_host/rv_decode/xesppie.S`, commit `7101770dc6db2667b3c477cc31365dd1acd6db4e`.

## Interpretation limits

Presence here means the pinned Espressif source corpus contains an assembler example with this spelling. It does **not** prove:

- stable public instruction semantics or encoding;
- latency or issue throughput;
- availability in LLVM/Clang;
- ABI rules for the custom state;
- compatibility with a different compiler/IDF release;
- suitability for the selected silicon revision.

The six `esp.lp.*` hardware-loop mnemonics are included because they occur in the same custom decoder corpus, although the TRM treats hardware loops as a separate custom extension. The TRM also lists a seventh conceptual operation, `lp.setup.beqz`, which is absent from this corpus.

Do not derive code from the name alone. Compile a probe, inspect the encoding, use an authoritative semantic source/intrinsic where available, and compare the result against a scalar oracle.
